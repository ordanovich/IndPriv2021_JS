# terria_frontend

TerriaJS 8.11.3 frontend for the Atlas de Privación de España viewer.

See the [project README](../README.md) for full documentation: architecture, features, build instructions and deployment guide.

## Quick start

```bash
npm install --legacy-peer-deps
npx gulp dev          # dev server at http://localhost:3001
npx gulp build-app    # production build → wwwroot/build/
```
